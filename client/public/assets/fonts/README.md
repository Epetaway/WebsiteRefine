# Self-hosted fonts

Latin-subset WOFF2 files are self-hosted to remove a render-blocking third-party request:

- Manrope — Google Fonts / SIL Open Font License 1.1
- Source Serif 4 and Source Serif 4 Italic — Adobe/Google Fonts / SIL Open Font License 1.1
- JetBrains Mono — JetBrains/Google Fonts / SIL Open Font License 1.1
- Barlow Condensed 600/700/800 — @fontsource/barlow-condensed (via the Earl the Kaiju website repo) / SIL Open Font License 1.1, `OFL-barlow-condensed.txt`. Loaded only by the Earl the Kaiju case study stylesheet.

Source and license records:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/sourceserif4
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
- https://github.com/google/fonts/tree/main/ofl/barlowcondensed

Do not replace these files without updating the source/version and license record.
