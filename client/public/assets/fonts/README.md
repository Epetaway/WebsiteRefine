# Self-hosted fonts

Latin-subset WOFF2 files are self-hosted to remove a render-blocking third-party request:

- Manrope — Google Fonts / SIL Open Font License 1.1
- Source Serif 4 and Source Serif 4 Italic — Adobe/Google Fonts / SIL Open Font License 1.1
- JetBrains Mono — JetBrains/Google Fonts / SIL Open Font License 1.1
- Barlow Condensed 600/700/800 — @fontsource/barlow-condensed (via the Earl the Kaiju website repo) / SIL Open Font License 1.1, `OFL-barlow-condensed.txt`. Loaded only by the Earl the Kaiju case study stylesheet.
- Inter 400/500/600/700 — @fontsource/inter 5.3.0 latin subset / SIL Open Font License 1.1, `OFL-inter.txt`. WithYou's and DojoNet's product typeface; loaded only by those two case study stylesheets.
- Orbitron 600/700 — @fontsource/orbitron 5.3.0 latin subset / SIL Open Font License 1.1, `OFL-orbitron.txt`. Gundam Forge's display face; loaded only by the Gundam Forge case study stylesheet.
- Exo 2 400/500/600/700 — @fontsource/exo-2 5.3.0 latin subset / SIL Open Font License 1.1, `OFL-exo-2.txt`. Gundam Forge's text face; loaded only by the Gundam Forge case study stylesheet.
- Bebas Neue 400 — @fontsource/bebas-neue 5.3.0 latin subset / SIL Open Font License 1.1, `OFL-bebas-neue.txt`. DojoNet's display face; loaded only by the DojoNet case study stylesheet.
